# Ручная проверка на Windows

Код под Windows собирается кросс-компиляцией из Linux, но запустить его там
нельзя. Этот список проверяет то, что можно увидеть только на настоящей
машине. Результат каждого пункта (успех, или что именно произошло) нужно
вернуть разработчику.

Нужны: ПК с Windows 10/11, учётка администратора и учётка ребёнка без прав
администратора, сервер из `deploy/` в той же сети.

## Подготовка

1. Собрать бинарники: `just dist-windows` (или `cargo build --release
   --target x86_64-pc-windows-gnu -p parentcontrol-agent -p parentcontrol-tray`)
   и скопировать `parentcontrol-agent.exe` и `parentcontrol-tray.exe` на ПК
   в одну папку.
2. В панели: «Устройства» → «Получить код».

## Установка (под администратором, PowerShell «от имени администратора»)

| # | Действие | Ожидается |
|---|---|---|
| 1 | `.\parentcontrol-agent.exe install` | «Служба установлена и запущена». В `services.msc` есть «Parent Control», тип запуска «Автоматически», вход от «Локальной системы» |
| 2 | `& "C:\Program Files\ParentControl\parentcontrol-agent.exe" enroll --server https://192.168.1.135:8443 --code <код>` | «Устройство подключено», отпечаток совпадает с панелью |
| 3 | В панели «Устройства» | Устройство «в сети», платформа Windows, в списке учётных записей есть учётка ребёнка |
| 4 | Привязать учётку ребёнка | Устройство больше не «не настроено» |
| 5 | `C:\ProgramData\ParentControl` → Свойства → Безопасность | Только SYSTEM и Администраторы, наследование отключено |
| 6 | `services.msc` → «Parent Control» → Восстановление | Перезапуск службы при первом, втором и последующих сбоях |

## Ограничения (под учёткой ребёнка)

| # | Действие | Ожидается |
|---|---|---|
| 7 | Квота 1 мин, запустить Minecraft из официального лаунчера | Через ~1 мин игра закрыта (до трея — принудительно, через 30 с после конца квоты) |
| 8 | То же из Prism Launcher | То же |
| 9 | Запустить снова | Процесс игры завершается в пределах 5 секунд |
| 10 | Скопировать `javaw.exe` под другим именем и запустить игру через него (Prism: свой путь к Java) | Тоже обнаруживается и закрывается |
| 11 | Вне окна разрешённого времени запустить игру | Завершается сразу |
| 12 | Перезагрузить ПК, снова запустить игру при исчерпанной квоте | Завершается сразу (учёт пережил перезагрузку) |

## Защита (под учёткой ребёнка)

| # | Действие | Ожидается |
|---|---|---|
| 13 | `sc stop ParentControl` | «Отказано в доступе» |
| 14 | Диспетчер задач → завершить `parentcontrol-agent.exe` | Отказано |
| 15 | Открыть или удалить файлы в `C:\ProgramData\ParentControl` | Отказано |
| 16 | Заменить файлы в `C:\Program Files\ParentControl` | Отказано |
| 17 | Сменить системное время (Параметры → Время) | Нет прав; смена часового пояса не влияет на окна (они по часовому поясу сервера) |
| 18 | Выдернуть сеть, поиграть, вернуть сеть | Ограничения действуют; в «Истории» время помечено «офлайн» |

## Что прислать

- Номера пунктов, которые не прошли, и что произошло вместо ожидаемого.
- Файл `C:\ProgramData\ParentControl\agent.log` (открыть под администратором).
- Для пунктов 7–10: командную строку процесса игры, пока он запущен:
  `Get-CimInstance Win32_Process -Filter "Name like 'java%'" | Select-Object -Expand CommandLine`
  (заменить токены и имя пользователя на `redacted`). Это пойдёт в фикстуры
  детекта.
